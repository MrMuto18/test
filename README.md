# 🌾 فلاحين - منصة فلاحية تونسية

موقع فلاحي متكامل يوفر:
- 🛒 متجر منتجات فلاحية
- 💬 استشارات ذكية
- 📊 لوحة تحكم Admin

## 🚀 Live Demo

Deploy على Vercel أو Netlify

## 📦 المميزات

- ✅ Dynamic Products من Firebase
- ✅ Admin Panel كامل
- ✅ Responsive Design
- ✅ تسجيل دخول متعدد (Email, Google, Facebook)

## 🔧 التشغيل

1. افتح `index.html` في المتصفح
2. استخدم `seed-data.html` لتحميل البيانات الأولية
3. سجّل دخول Admin: `admin@falla7in.com` / `admin123`

## 📁 الهيكل

```
.
├── index.html              # الصفحة الرئيسية
├── shop.html               # المتجر (Dynamic)
├── consultation.html       # الاستشارة (Dynamic)
├── seed-data.html          # تحميل البيانات
└── admin/
    ├── index.html          # تسجيل دخول Admin
    ├── dashboard.html      # لوحة التحكم
    ├── products.html       # إدارة المنتجات
    └── questions.html      # إدارة الأسئلة
```

## 🔥 Firebase Setup

1. إنشاء مشروع في Firebase Console
2. تفعيل Firestore Database
3. تفعيل Authentication
4. تفعيل Storage
5. تحديث Firebase config في الملفات
